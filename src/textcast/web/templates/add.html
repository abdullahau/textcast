From the iPhone share sheet

Android posts straight to this app once you install it. iOS has no share target, so it needs a Shortcut. Build it once:

  1. Open Shortcuts, make a new shortcut, and add Get Contents of URL.
  2. Set the URL to {{ request.base_url }}api/ingest.
  3. Set Method to POST and Request Body to Form.
  4. Add a field kind with the value url.
  5. Add a field url and set its value to Shortcut Input.
  6. If you turned on access control, add a header x-textcast-token holding your token.
  7. In the shortcut details, turn on Show in Share Sheet and accept URLs.

Share any page to it and the article is waiting in your library, parsed.
