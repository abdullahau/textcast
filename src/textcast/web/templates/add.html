From the iPhone share sheet

Android posts straight to this app once you install it. iOS has no share target, so it needs a Shortcut. Build it once:

  1. Open Shortcuts, make a new shortcut, and add Get Contents of URL.
  2. Set the URL to {{ origin }}/api/ingest.
  3. Set Method to POST and Request Body to Form.
  4. Add a field kind with the value url.
  5. Add a field url and set its value to Shortcut Input.
    6. {% if token %}
  6. Add a field token and paste this as its value:
    {{ token }}
    Paste it. Do not type it: an iPhone turns a hyphen into a dash and the token stops matching.
    7. {% endif %}
  7. Add Show Result at the end, with Contents of URL as its input. Without it a refusal looks exactly like success.
  8. In the shortcut details, turn on Show in Share Sheet and accept URLs.

Share any page to it. Show Result names the article on success, and says what went wrong on failure. A header called x-textcast-token still works, if you already built the shortcut that way.

From the iPhone, past a paywall

The shortcut above sends the link, and the server then fetches it as a stranger — so a paywall wins on a phone and loses on a laptop, where the bookmarklet sends the page instead. This second shortcut sends the page: Safari reads it while you are signed in, and the HTML it already has is what is posted. Build it once, as a second shortcut:

  1. New shortcut. Add Run JavaScript on Web Page — it appears only when the shortcut accepts Safari web pages, so set that first in the shortcut details.
  2. Replace the sample script with exactly this:
    completion(document.documentElement.outerHTML)
  3. Add Get Contents of URL with the URL {{ origin }}/api/ingest, Method POST, Request Body Form.
  4. Add a field kind with the value html.
  5. Add a field html and set its value to the result of Run JavaScript on Web Page.
  6. Add a field url and set its value to Shortcut Input. The page carries the words; the link is what says where they came from, which publication parsed it, and what “original” points at.
    7. {% if token %}
  7. Add a field token and paste this as its value:
    {{ token }}
    8. {% endif %}
  8. Add Show Result at the end, with Contents of URL as its input.
  9. In the shortcut details, turn on Show in Share Sheet and accept Safari web pages — not URLs. That is the whole difference: a URL is a link, a Safari web page is the page.

Share from Safari’s own share button, not from a link. Some sites load the article after the page, so if a share comes back short, let it finish rendering and share again. Keep both shortcuts: this one needs Safari, and the first one takes a link from anywhere.

One click from any page

Drag this to your bookmarks bar. It posts the page your browser has, already rendered and already logged in, so the server never has to get past the wall. That is what the share sheet cannot do: the sheet sends the link, and the server fetches it as a stranger.

It posts to {{ origin }}/api/ingest. A browser refuses to post from an https page to an http one, so on a paywalled site this needs textcast behind TLS. Set TEXTCAST_PUBLIC_URL to the address the outside world uses.
