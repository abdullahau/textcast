What this does

A summary of each section is written as a block at the top of that section, so it is read aloud before the section itself, highlighted like any other paragraph, and searchable. Turn it off per article with Show summaries in the player, or skip it in the audio with Skip summaries.

Any endpoint that speaks the OpenAI protocol works, so the model is yours to choose. Summarising queues a rebuild, because a new block moves the paragraphs after it.

Model

Any endpoint that speaks the OpenAI protocol works, which today is nearly all of them. Picking a provider fills in its address and suggests models; you can type any model name the endpoint accepts, and edit the address for anything not listed.

Kept in the database on this machine. Leave blank to keep the one already stored. TEXTCAST_SUMMARY_API_KEY or GEMINI_API_KEY supplies it when nothing is stored. A local Ollama needs no key — put anything in it.

{text} is where the section goes. It is written for the ear: no markdown, no bullets, nothing a voice would read out as punctuation.

Saving stores the settings and nothing else. No article is summarised until you ask for one.
