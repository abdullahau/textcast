What this does

A summary of each section is written as a block at the top of that section, so it is read aloud before the section itself, highlighted like any other paragraph, and searchable. Turn it off per article with Show summaries in the player, or skip it in the audio with Skip summaries.

Any endpoint that speaks the OpenAI protocol works, so the model is yours to choose. Summarising queues a rebuild, because a new block moves the paragraphs after it.

API keys

One key per endpoint, kept in the database on this machine. Storing a key does not switch to that provider — choose that below. A local Ollama or LM Studio needs no key at all.
